# task-2-email-template
Codsoft UI/UX Internship - Task 2: Email Template

## ✉️ Project Overview

A clean, professional email template designed for marketing or announcements. The layout includes:
- Eye-catching header with a CTA
- Structured body text with visuals
- Footer with contact and social links

The goal was to ensure visual hierarchy, readability, and responsiveness across devices.
